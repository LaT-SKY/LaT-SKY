### 关于

大二在读。空闲的时间基本都花在 Linux 上了。

折腾的范围很小，主要集中在 Arch 系：壁纸、发行版、游戏启动器。
写代码主要用 **Node.js**、**Python** 和 **Rust**。

不写代码的时候喜欢看番、打歌。

### 在做

#### **[MipLinux](https://github.com/MipLinux/MipLinux)** 
    基于 Arch 的发行版，中文和 N 卡友好。
#### **[mip-paper](https://github.com/LaT-SKY/mip-paper)** 
    Plasma 的动态壁纸引擎，可以在 AUR 上下载体验。
#### **[Oddity](https://github.com/LaT-SKY/Oddity)** 
    《异环》的 Linux 启动器。
